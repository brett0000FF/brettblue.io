# brettblue.io

Personal site for Brett Blue, built with [Astro](https://astro.build) and deployed to GitHub Pages.

## Update the content

All resume content lives in [`src/data/resume.ts`](src/data/resume.ts). Edit it and push to `main`; the GitHub Actions workflow builds and publishes the site.

## Run locally

Requires Node 22 or later.

```bash
npm install
npm run dev
```
